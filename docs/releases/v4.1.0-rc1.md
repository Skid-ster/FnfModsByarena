# v4.1.0-rc1 — soundtrack and presentation testing release

**Testing release, not a final quality or compatibility sign-off.** The full
songs have not been auditioned here, and the mod has not been play-tested in
Codename Engine. Shaders, menus, gameplay and the mix need real-world testing.
Flashes, static and jumpscares are present.

## What's new

- Five original arrangements feature CC0 recorded upright piano, distinct
  three-note answers, phrase-shaped vocal dynamics, and section-based rises and
  retreats. The existing chart melodies and timings are preserved. Both
  characters use different pitches of the same recorded vowel; these are not
  official BF or Trollge recordings.
- The cinematic menu and refreshed countdown/health UI are included. Four arrow
  skins have clearer lane colours and seamless hold-body edges. The HUD remains
  spatially steady while effects play on the game camera.
- The game-camera grade has been softened to preserve dark detail. Event camera
  shake and zoom are bounded; unrelated camera filters are preserved.
- CC0 piano and voice notices are included in the archive as
  `THIRD_PARTY_NOTICES.txt`. Source, samples and detailed notes are in the repo.

## Install

1. Download **`TrollgeMod.zip`** below.
2. Put the zip in Codename Engine's `mods/` folder, or extract it as
   `mods/TrollgeMod/`.
3. Launch Codename Engine and enable the mod. Check Story and Freeplay.

The versioned archive is identical, but `TrollgeMod.zip` is the recommended
install name for the supplied Freeplay compatibility lists. Engine builds can
resolve libraries differently. This is a Codename Engine mod, not Psych Engine.

## Validation and limitations

The source passes asset/chart validation, shader syntax compilation against a
minimal interface, numeric audio checks, decoded equal-gain stem peak checks,
and an archive-level Freeplay lookup model. These are **not** a GPU test,
listening test, or proof of in-engine behavior. Please test all five songs,
voices, menus, arrows/holds, flashes, shaders, Freeplay and ending in your
actual engine build before relying on this as a finished release.
