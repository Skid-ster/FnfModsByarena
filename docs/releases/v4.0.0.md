# v4.0.0 — testing release

This is a testing build, not a final sound or gameplay sign-off.

- All five songs have rebuilt vocals using a CC0 recorded sung vowel, pitched
  to the existing chart onsets; both characters use the same source in different
  registers. These are not the official BF or Trollge voice recordings.
- The lead, stereo width and vocal mix have been rebalanced; the original
  authored chart phrases and song structures remain.
- The main menu is rebuilt around the cinematic reference, with refreshed HUD,
  contact shadows and camera polish.

Install **TrollgeMod.zip** in Codename Engine's `mods/` folder. The versioned
ZIP has the same contents. Listen to the full songs and test character vocals,
Freeplay, menu layout, stage framing and effects in your engine build. Neither
playback nor engine gameplay could be tested in the build environment.

Vocal source: [Bart Massey's voice-note.wav](https://github.com/pdx-cs-sound/wavs)
(CC0), modified by trimming, filtering, looping, pitch-shifting and enveloping.
See the README and `docs/music-research.md` in the source for further details.
